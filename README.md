# Exam Results Management System

## Description
A simple web application to manage and display student examination results. The system allows users to add student marks and automatically calculates total marks and pass/fail status.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Features
- Add student results
- Automatic total calculation
- Pass/Fail result generation
- View student results in a table

## Project Structure
```
exam-results-management-system
│
├── app.py
├── database.db
└── templates
    ├── index.html
    ├── add_result.html
    └── results.html
```

## Run the Project
```
pip install flask
python app.py
```

Open in browser:
```
https://exam-results-management-system.onrender.com/results```
